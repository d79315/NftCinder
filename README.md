# NftCinder

NftCinder provides a distributed cloud framework for real-time data processing and auto-scaling, enabling scalable platform infrastructure.

NftCinder is built to be simple and practical, focusing on doing one thing well.

**Why NftCinder?**

- and auto-scaling, enabling scalable platform

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftCinder.git`
2. `cd NftCinder`
3. Install in editable mode: `pip install -e .`

## Configuration

NftCinder is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
